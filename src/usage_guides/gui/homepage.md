# Homepage
![Homepage]()
The Homepage is the main dashboard for the laser vision system, it shows the current deviation values for the cameras which have been calibrated in a clear and easy-to-understand layout.

`The key features of the homepage include:`
- `Deviation Alerts`
  - The deviation alerts display a camera's deviation corresponding to their set thresholds via colour-coded messages.
- `Connected and Disconnected Devices`
- `Device Management`
- `Deviation Detection`
- `Camera Information`
- `Camera Feed `
