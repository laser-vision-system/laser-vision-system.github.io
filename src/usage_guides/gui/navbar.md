# NavBar

![NaveBar](./images/navbar.png)
The NavBar, short for navigation bar, is used to switch between different pages of the application. The NavBar icon changes to show a red light, referencing the currently selected page.

From the NavBar the user is able to get to the 3 main pages:

- [The Homepage](./homepage.md)
- [Device Settings](./device_settings.md)
- [Global Settings](./global_settings.md)
