# NavBar

![NavBar](./images/navbar.png)
The NavBar, short for navigation bar, is used to switch between the different pages of the site. The NavBar icon of the currently selected page shows a red light to indicate which one is currently selected.

From the NavBar, you can swap between the three main pages:

- [Homepage](./homepage.md)
- [Device Settings](./device_settings.md)
- [Global Settings](./global_settings.md)
