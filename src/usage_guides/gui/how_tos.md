## How to Configure a Camera
To configure a camera either click the configure button in the camera info panel when the camera is selected on the homepage, or go to the device settings page and  use the drop down menu under the camera settings section to to select the desired camera, in the case of too many options the microcomputer can also be selected to filter the camera options by the microcomputer they are physically connected to.

### How to Rename a Camera
1. Ensure that the desired camera is selected in the select camera section, located under the Camera Configuration.
2. Directly under the select camera option, you should see the rename camera option. Simply click on the text box and type in the desired name.
3. To save the new name to the camera name, just click the `Rename` button on the right of the text box and click confirm on the popup message. 

We advise to name the camera based on what it is observing or is position in the laser lab, to provide context on what is being observed and where the camera is physically in the laser lab.

### How to Configure the Camera Controls
1. Ensure that the desired camera is selected in the select camera section, located under the Camera Configuration.
2. Directly under the rename camera section of the camera settings, you can find the camera controls section, which should list the controls that are available to the selected camera. 
3. You can either can use the slider or type in the desired value for the control if they are integer range. In the cases of menu control simply selected the desired menu option from the drop down.
4. To save any changes made to the camera controls click the `Save Camera Controls` button.

To reset any changes made to the camera values simply click the `Reset Camera Controls` button which will set all control values to their respective defaults, to apply these changes just click the `Save Camera Controls` button.

### How to set a Custom Threshold Deviation for a Camera.
1. Ensure that the desired camera is selected in the select camera section, located under the Camera Configuration.
2. The configuration for the deviation thresholds is located directly under the camera controls section.
3. The deviation thresholds can be configured via the multi thumb slider or via the respective number inputs underneath the slider.
4. Any changes made to the threshold can be saved by clicking the `Save Thresholds` button.

#### How to save the Global Default for the Deviation Thresholds 
To set a new global default values for the deviation thresholds simply used the same slider as used in setting the cameras deviation value. However instead of clicking the save thresholds button click the `Save Global Default Thresholds` button. This will set the threshold values selected as the global default and save it to the server.

**To test the change has taken place:**
1. Change the values on the slider. 
2. Then click the `Reset to Default` button and see if the values match the ones that were saved as the global default. 
## How to Configure the Deviation Slider's Range
1. To configure the deviation sliders range you must first have a camera selected.
2. Then in the deviation thresholds section of the camera settings. Click on the `Configure Range` button, located to the right of the Deviation Thresholds section label.
3. When the button is clicked the option to edit the min and max of the deviation scale are shown.
4. To save the new configured range, click the `Set Range` button.

To set the new configured range to the applications default click the `Set Default Range` button.

To reset the new configured range to the previously saved values click the `Cancel` button.

To close the range configuration simply click the `Close Configuration` button located in the same location as the Configure Range button.

## How to Configure a microComputer
A micro computer can be configured through the homepage by clicking the configure button next the the name of the microcomputer in the connections tab of the homepage, alternatively you can go to the device settings page and select the microcomputer you wish to configure using the drop down menu. 
### How to Rename a microComputer
To Rename a microcomputer which is connected to the system:
1. Select the desired microcomputer from the drop down menu directly under the microcomputer configuration section.
2. When selected the microcomputer configuration options should appear below.
3. Click on the text box with the Rename microcomputer label and enter the new name of the microcomputer. We advise a consistent naming scheme of your choice to avoid any confusion.
4. To save the new name of the microcomputer click the `Rename` button next to the text box. 
### How to Select a Vision Processing Technique
To select a vision processing technique for the microcomputer:
1. ensure that the desired microcomputer is selected
2. underneath the rename configuration option there is an options to select vision processing, click on the drop down menu and select the desired vision processing for the microcomputer.
3. To save the selection click the `Select` button on the right of the drop down menu.
## How to Change the Theme
To alternate from the dark and light themes in the Global Setting page, click the toggle under the themes label. We Strongly recommend the dark theme as not much effort has been put into the light theme.
