NavBar

The NavBar, short for navigation bar, is used to switch between the different pages of the site. The NavBar icon of the currently selected page shows a red light to indicate which one is currently selected.

From the NavBar, you can swap between the three main pages:

  • The Homepage
  • Device Settings
  • Global Settings

Homepage

The Homepage is the main dashboard for the laser vision system. On it, you will find all information needed for standard operation.

Alerts

At the top of the page is the alerts section.

It displays important information such as deviation warnings or device disconnection events. This section can be collapsed if necessary.

Main Section

The main body of the page is information about all devices known by the system.

The first tab shows all currently connected devices while the second tab shows devices that have been disconnected or have encountered an issue that prevents them from operating.

Connections

This tab shows all currently connected devices.

The cameras are grouped by the edge computing device that they are connected to.

Each connected camera that has been calibrated will show the current deviation value and be coloured to alert if the deviation has drifted outside a set threshold using a stoplight colour system.

There is a button for each edge computing device to quickly access configuration options for it.

You can select a camera to view more details about it and calibrate the deviation measurement.

Disconnections

This tab shows devices that are no longer connected to the system.

Each device has a button to forget the camera completely. Faulty cameras have a button to manually force a reconnection attempt.

Device Settings

The Device Settings section is for the configuration of the devices used in this project, such as the cameras and microComputers that are currently being used.

Edge Device Settings

Edge devices refer to the Raspberry Pi(s) that is used to run the edge. The edge can also be run on any computer. However, using a microComputer such as the Raspberry Pi is recommended due to its small form factor that fits well in the tightly-packed laser lab.

The connected Edge devices can be configured to:

  • Be selected to filter the specific options for all the connected cameras, displayed in the camera configuration below.
  • Be renamed, allowing the user to give a meaningful identifier to the device.
  • Run a specific vision processing technique. Note: this will select the processing technique for all cameras connected to the microComputer.

Cameras

The cameras that can be configured are the ones that are connected to the system, and have their state as active.

The connected Cameras can be configured to:

  • Rename the selected camera to a more meaningful name (e.g. what it is observing).
  • Change the selected camera controls for tweaks to help improve the vision processing. Some camera controls to consider are:
    • PUT IMPORTANT CAMERA CONTROLS HERE
  • Set the deviation thresholds for the selected camera (e.g. if a camera is misbehaving and needs a custom deviation range to keep it in check).
  • The range (min - max) of the deviation threshold input slider can be configured to suit the needs of the camera’s threshold setup, allowing for fine-tuning of the deviation thresholds.

Global Settings

The Global Settings section is for the configuration of the underlying aspects of the system. It is split into two sections: one for the GUI and the other for the server which includes the default server settings.

GUI settings

The global settings for the GUI include:

  • A toggle for the theme of the user interface, it allows the user to switch between light and dark mode. (Dark mode is recommended.)
  • A toggle for the viewing of the camera feed applicable to the whole application. This helps to declutter the UI.

Server Settings

The global settings for the server defaults include:

  • Web-Socket poll interval
  • Update Delay
  • Camera Error Decrement
  • Camera Error Increment
  • Camera Error Threshold

How Tos

Short guides for how to complete certain tasks using the GUI.

Configure Edge Devices

How to Configure Edge Devices

An edge device can be configured through the homepage by clicking the configure button next the the name of the microcomputer in the connections tab of the homepage, alternatively you can go to the device settings page and select the microcomputer you wish to configure using the drop down menu.

Rename Edge Device

How to Rename an Edge Device

To Rename an Edge device which is connected to the system:

  1. Select the desired Edge Device from the drop down menu directly under the Edge Device configuration section.
  2. When selected the Edge Device configuration options should appear below.
  3. Click on the text box with the Rename Edge Device label and enter the new name of the Edge Device. We advise a consistent naming scheme of your choice to avoid any confusion.
  4. To save the new name of the Edge Device click the Rename button next to the text box.

Select Vision Processing

How to Select a Vision Processing Technique

To select a vision processing technique for the microcomputer:

  1. ensure that the desired microcomputer is selected
  2. Underneath the rename configuration option there is an options to select vision processing; click on the drop-down menu and select the desired vision processing technique for the microcomputer.
  3. To save the selection click the Select button on the right of the drop-down menu.

Configure Cameras

How to Configure a Camera

To configure a camera, either click the ‘Configure’ button in the Camera Info panel when the camera is selected on the homepage, or go to the device settings page and use the drop-down menu under the camera settings section to select the desired camera for configuration. In the case of too many camera options, the microcomputer can also be selected to filter the camera options by the microcomputer they are physically connected to.

Rename Camera

How to Rename a Camera

  1. Ensure that the desired camera is selected in the select camera section, located under the Camera Configuration.
  2. Directly under the select camera option, you should see the rename camera option. Simply click on the text box and type in the desired name.
  3. To save the new name to the camera name, just click the Rename button on the right of the text box and click confirm on the popup message.

It is advised to name the camera based on what it is observing or its position in the laser lab, thus providing meaningful context.

Configure Camera Controls

How to Configure the Camera Controls

  1. Ensure that the desired camera is selected in the select camera section, located under the Camera Configuration.
  2. Directly under the rename camera section of the camera settings, you can find the camera controls section, which should list the controls that are available to the selected camera.
  3. You can either use the slider or type in the desired value for the control. In the cases of menu control simply select the desired menu option from the drop-down.
  4. To save any changes made to the camera controls click the Save Camera Controls button.

To reset any changes made to the camera values simply click the Reset Camera Controls button which will set all control values to their respective defaults, to apply these changes just click the Save Camera Controls button.

Configure Camera Deviation Thresholds

How to set a Custom Threshold Deviation for a Camera.

  1. Ensure that the desired camera is selected in the select camera section, located under the Camera Configuration.
  2. The configuration for the deviation thresholds is located directly under the camera controls section.
  3. The deviation thresholds can be configured via the multi-thumb slider or via the respective number inputs underneath the slider.
  4. Any changes made to the threshold can be saved by clicking the Save Thresholds button.

How to save the Global Default for the Deviation Thresholds

To set a new global default values for the deviation thresholds simply used the same slider as used in setting the cameras deviation value. However instead of clicking the save thresholds button click the Save Global Default Thresholds button. This will set the threshold values selected as the global default and save it to the server.

To test the change has taken place:

  1. Change the values on the slider.
  2. Then click the Reset to Default button and see if the values match the ones that were saved as the global default.

Configure Deviation Slider Range

How to Configure the Deviation Slider’s Range

  1. To configure the deviation sliders range you must first have a camera selected.
  2. Then in the deviation thresholds section of the camera settings. Click on the Configure Range button, located to the right of the Deviation Thresholds section label.
  3. When the button is clicked the option to edit the min and max of the deviation scale are shown.
  4. To save the new configured range, click the Set Range button.

To set the new configured range to the application’s default click the Set Default Range button.

To reset the new configured range to the previously saved values click the Cancel button.

To close the range configuration simply click the Close Configuration button located in the same location as the Configure Range button.

How to Toggle the Camera Feed

The camera feed can be toggled globally which will toggle the camera feeds initial state, from either showing or not showing. The camera feed can also be toggle locally within the homepage and the device settings tabs, allowing the user to control the homepage’s visibility.

Toggling the live camera feed doesn’t only stop the feed from showing on the GUI, it sends a request to the server to stop the viewing altogether. This can be very useful to not bloat the local lab’s network with a live camera feed when it is not needed and save the network’s bandwidth which could be a big help at a larger scale.

How to Toggle the Camera Feed Globally

Located in the global settings tab under the theme toggle there is a sliding check box with the label of Automatic Camera Feed, simply click on the sliding check box to toggle the global camera feed.

How to Toggle the Camera Feed Locally

Homepage

In the homepage tab the camera feed can be enabled / toggled by selecting a camera and clicking on the View Live Feed button, to disable or un-toggle the camera feed simply click the same button which has been renamed to Hide Live Feed

Device Settings

In the device settings tab simply click on the arrow button, on the left of the Camera Feed label. This is in line with how the rest of the section toggles work in the settings tabs, when the arrow is pointing up it means that the section is hidden, if the arrow is pointing down it means that the section is visible.

Change Theme

How to Change the Theme

To alternate between dark and light themes in the Global Settings page, click the toggle under the themes label.

How to Configure the Server Settings

Location

The server settings can be configured via the global settings tab, located under the GUI settings section the server settings section has all the settings that can be changed on the server to effect its behaviour. These settings are kept by the server and sent to any edge device (microcomputer) that connects to the server, hence why they are often referred to as the default server settings.

How to Configure

Similar to the camera controls these settings can be either changed via the sliders or a number input, they all have their respective range and validation to check that the values they are configured to are valid.

Saving the server values

The server values can be save by clicking the Save Server Defaults button when this is clicked the values set will be validated then once deemed valid they are sent to the server via a post request.

Resetting the Server values

The server defaults are hard coded on the user interface, to reset to the default values, click on the Reset Server Defaults button, then to save this change click on the Save Server Defaults button.

To Note

The value of the camera error decrement is not allowed to be lower than the camera error increment. If this is done the custom validation will tell you off with a warning making it impossible to save the values when they are out of their respective bounds.
